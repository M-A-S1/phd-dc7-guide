# Encrypted website build

This repository holds only the published build of a private, password-protected website,
served with GitHub Pages. Every page is encrypted with [StatiCrypt](https://github.com/robinmoisson/staticrypt)
(AES-256) before it is pushed here, so nothing in it can be read without the password.
The source is kept in a private repository. Search engines are blocked (robots.txt and noindex).
